**Подготовка и приёмка товара**

1. Оператор регистрирует ожидаемую поставку.
2. Система создаёт накладную и указывает срок ожидаемой поставки.
3. Для каждой позиции указывается ожидаемое количество товара.
4. Система рассчитывает необходимый объём для размещения.
5. Система проверяет наличие свободного места в ячейках хранения.
6. При наличии места система резервирует необходимый объём ячейки.
7. Оператор получает информацию о подготовленном месте.
8. После прибытия поставки кладовщик открывает соответствующую накладную.
9. Кладовщик сканирует поступивший товар и указывает фактическое количество.
10. Система создаёт информацию о фактической поставке.
11. Для каждой позиции система сравнивает ожидаемое и фактическое количество.
12. При совпадении количества система принимает товар и создаёт партию товара.
13. Система снимает резерв с подготовленной ячейки.
14. Приёмка товара завершается.


**Размещение товара на складе**

1. Кладовщик получает задание на размещение принятой партии.
2. Система определяет подготовленную ячейку для товара.
3. Система проверяет доступный объём ячейки.
4. Кладовщик получает адрес ячейки.
5. Кладовщик перемещает товар к указанной ячейке.
6. Кладовщик подтверждает размещение.
7. Система помещает партию товара в ячейку.
8. Система увеличивает занятый объём ячейки.
9. Система снимает ранее установленный резерв.
10. Размещение товара завершается.


**Отбор и комплектация заказа**

1. Оператор создаёт складской заказ.
2. Для каждой позиции заказа указывается необходимое количество товара.
3. Система проверяет наличие необходимого товара.
4. Для каждой позиции система находит подходящую партию товара.
5. Система определяет ячейку, в которой находится партия.
6. Система формирует задание на отбор.
7. Кладовщик получает задание с адресом ячейки.
8. Кладовщик перемещается к указанной ячейке и отбирает товар.
9. Кладовщик подтверждает отбор.
10. Система увеличивает фактически отобранное количество в позиции заказа.
11. Система уменьшает количество товара в выбранной партии.
12. Система уменьшает занятый объём ячейки.
13. Система проверяет комплектность заказа.
14. Если все позиции отобраны, заказ получает статус «Укомплектован».
15. Комплектация заказа завершается.


**Инвентаризация и контроль остатков**

1. Оператор запускает инвентаризацию.
2. Система создаёт сессию инвентаризации.
3. Система формирует список проверяемых ячеек.
4. Для каждой ячейки система создаёт запись проверки.
5. Система получает ожидаемое количество товара.
6. Кладовщик проверяет фактическое наличие товара в ячейке.
7. Кладовщик вводит фактическое количество.
8. Система сохраняет фактическое количество.
9. Система рассчитывает разницу между ожидаемым и фактическим количеством.
10. Если количество совпадает, позиция отмечается как проверенная.
11. Если обнаружена недостача или излишек, система формирует уведомление.
12. После проверки всех ячеек оператор завершает инвентаризацию.
13. Результаты инвентаризации сохраняются.


**Отгрузка товара**

1. Менеджер оформляет отгрузку.
2. Система создаёт исходящую накладную.
3. Для каждой позиции указывается ожидаемое количество товара.
4. Система связывает отгрузку с соответствующим складским заказом.
5. Система проверяет наличие необходимого товара.
6. Кладовщик получает задание на отбор товара.
7. Кладовщик отбирает товар и подтверждает фактическое количество.
8. Система создаёт отгрузку и позиции отгрузки.
9. Система сравнивает ожидаемое и фактическое количество.
10. При совпадении количества товар передаётся в зону отгрузки.
11. Оператор проверяет подготовленный товар.
12. Оператор подтверждает отгрузку.
13. Система выполняет операцию отправки.
14. Заказ получает статус «Отгружен».
15. Отгрузка завершается.
