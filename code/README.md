# Информационная система склада на C++

Консольная программа для лабораторной работы. Учитывает поступление товара,
размещение по местам хранения, сборку заказов, инвентаризацию со списанием,
отгрузку и уведомления.

## Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -pedantic \
    main.cpp storage.cpp warehouse_entities.cpp warehouse_system.cpp \
    -o warehouse_demo
./warehouse_demo
```

На Windows (MinGW) команда та же, запуск — `warehouse_demo.exe`. Кодировка консоли
переключается на UTF-8 автоматически в `main.cpp`.

## Меню

```text
==================================================
        ИНФОРМАЦИОННАЯ СИСТЕМА СКЛАДА
 Центральный склад, г. Москва, ул. Складская, 1
==================================================
 Ячейки: занято 1.80 из 12.00 м³ (резерв 0.00 м³), партий: 2
 Зона приёмки: 0 парт. | Зона отгрузки: 0 парт.
 Заказов всего: 0 | готовы к отгрузке: 0 | новых уведомлений: 0
--------------------------------------------------
 1. Показать структуру склада
 2. Подготовка и приёмка товара
 3. Размещение товара
 4. Создание и комплектация заказа
 5. Инвентаризация и списание
 6. Отгрузка товара
 7. Показать уведомления
 8. Выход
--------------------------------------------------
```

- Пользователь вводит номер пункта и нажимает Enter.
- Вверху — строка состояния склада: занятый объём, партии, заказы, новые уведомления.
- Ошибка ввода (например, `9` или `abc`) показывается прямо под меню.
- В каждом сценарии программа задаёт вопросы (товар, количество). **Enter без числа
  подставляет значение по умолчанию**, поэтому на защите можно пройти всё одними Enter.
- Каждый сценарий выводит: цепочку вызовов классов → работу методов → итог.

На складе сразу есть товар (молоко и сахар), поэтому любой пункт можно показать
без подготовки.

## Сценарии

| Пункт | Что происходит | Цепочка |
|---|---|---|
| 1 | Дерево склада: шкафы → полки → ячейки → партии, буферные зоны, свободный объём | WarehouseSystem → Warehouse → StorageCabinet → Shelf → StorageCell → GoodsBatch |
| 2 | Накладная, резерв места в ячейке, прибытие, пересчёт. Если привезли не столько, сколько в накладной, — приёмка с расхождением. Если места нет — товар ждёт в зоне приёмки или поставка отклоняется | WarehouseSystem → DeliveryNote → DeliveryNoteItem → Warehouse → StorageCell → GoodsBatch |
| 3 | Новая партия попадает в зону приёмки и раскладывается в первую подходящую ячейку. Можно разместить партии, которые ждут в зоне приёмки | WarehouseSystem → Warehouse → StorageCabinet → Shelf → StorageCell → GoodsBatch |
| 4 | Склад находит, где лежит товар, резервирует и отбирает его из партий, собранное переносит в зону отгрузки. Если товара мало — заказ собран частично | WarehouseSystem → WarehouseOrder → OrderItem → GoodsBatch |
| 5 | Пересчёт всех партий в ячейках. Недостача списывается, излишек оприходуется (изменение количества товара) | WarehouseSystem → StocktakeSession → StocktakeItem → StorageCell → Product |
| 6 | Выбор заказа, проверка соответствия собранного заказу. Полностью собранный заказ отгружается и уходит из зоны отгрузки, неполный — нет. Повторно отгрузить заказ нельзя | WarehouseSystem → Shipment → ShipmentItem → WarehouseOrder |
| 7 | Список уведомлений, новые отмечены `*` | WarehouseSystem → Notification |

## Связи классов

Композиция:

```text
Warehouse
 ├── StorageCabinet
 │    └── Shelf
 │         └── StorageCell
 └── BufferZone (зона приёмки, зона отгрузки)
```

Наследование:

```text
StorageLocation (абстрактный)
 ├── StorageCell
 └── BufferZone
```

`Warehouse`, `StorageCabinet` и `Shelf` не наследуются от `StorageLocation` — они
владеют вложенными объектами через `std::unique_ptr`.

`GoodsBatch` (партия) хранит количество, объём, резерв, статус и указатель на текущее
место хранения. Статусы партии: принята, на хранении, в буферной зоне,
зарезервирована, израсходована, отгружена.

Предметные классы:

- `Product` — товар;
- `DeliveryNote`, `DeliveryNoteItem`, `Delivery` — приёмка поставки;
- `WarehouseOrder`, `OrderItem` — заказ и его позиции;
- `StocktakeSession`, `StocktakeItem` — инвентаризация;
- `Shipment`, `ShipmentItem` — отгрузка;
- `Notification` — уведомление пользователя.

## Файлы

- `storage.h/.cpp` — склад, шкафы, полки, ячейки, буферные зоны, партии;
- `warehouse_entities.h/.cpp` — товар, приёмка, заказы, инвентаризация, отгрузка, уведомления;
- `warehouse_system.h/.cpp` — меню и сценарии;
- `main.cpp` — запуск.

Все основные методы печатают сообщение вида `Класс::метод: что сделано`, чтобы на
защите была видна цепочка вызовов. Геттеры (`getAddress`, `getCapacity` и т. п.)
ничего не печатают — они используются для строки состояния в меню.
